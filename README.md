# Electronic Nose Gas Sensor Analysis

## Overview
This is a simple and basic python project that presents an exploratory analysis of an e-nose gas sensor dataset. This is done to understand gas sensor responses through data preprocessing, visualization, and statistical analysis. This project also explores sensor behavior across multiple batches, providing insight into sensor drift over time.

## Dataset
The UCI Gas Sensor Array Drift Dataset was selected because of its relevence to current research in olfactory sensors. Sensory Drift, where sensor responses gradually change over time, affects the reliability of gas classification. Working with this benchmark dataset helped in understanding the data better and taught to deal with sensory drift challenge.

## Objectives
> Load and preprocess data
> Explore the characteristics of sensor responses
> Visualize feature distributions
> Analyze correlations between sensor features
> Investigate sensor drift across batches
> Perform dimensionality reduction using PCA

## Future work
